# Interface: SuggestTickTypeOptions

Options for [suggestTickTypeForRange](../functions/suggestTickTypeForRange.md).

## Properties

### minBins?

> `optional` **minBins**: `number`

Minimum number of ticks the range must span to qualify (default 1).

***

### maxBins?

> `optional` **maxBins**: `number`

Maximum number of ticks before a width is considered too fine (default 40).
